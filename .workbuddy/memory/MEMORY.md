# 项目长期笔记：WordStudy（F:\Word\mytool）

## 用户表达约定
- 「功能 1.2.4」「功能 1.2.3.4」这类点号串 = 主菜单功能编号的列举（如 1 看英选中、2 看中选英、3 看中拼写英、4 听音选中），不是三级章节号。
- 偏好一次改到位、少来回确认。

## 代码结构要点
- 主菜单 1/2/3/4 与错题本/自由练习的 `mode_*_with_words` 是两套独立实现，改界面显示时两边都要检查。
- 选择题统一由 `word_study.py` 的 `_ask_quiz()` 出题；`_prompt_choice()` / `_prompt_choice_with_replay()` 负责输入校验。
- `is_new` / `is_extra` / `practice_mode` 是 FSRS 调度与记录所需，不要因为界面不再显示图标而删除。
- 测试必须用项目 `.venv/Scripts/python.exe`（系统 Python 缺 `fsrs`）。

## 界面当前约定
- 选择题只显示 4 个选项（无「5. 不确定」），「请选择」与上一项的间距和每个选项之间一致（一个空行）。
- 全项目（源码 + README/FEATURES/QUICKSTART 等文档）不使用任何 emoji 图标，包括主菜单、子菜单、结果提示；框线、箭头、标点等排版字符保留。
- 唯一例外：功能 1/2/3/4 判题答错时显示错误图标，由 `word_study.py` 顶部的 `WRONG_ICON = '❌'` 统一定义（改标记只改这一处）；答对不显示任何图标。阅读训练界面仍保持纯文字。
- 阅读答题界面用纯文字「正确 / 错误 / 跳过」表示状态，当前题靠反色高亮区分。
- 用户偏好：界面保持纯文字、干净，不要图标装饰；上述错误图标是用户明确要求的单点例外。
